1 · Logique

Proposition Phrase soit vraie, soit fausse, pas les deux. Ex : 2+2=4 (V) ; 2×3=7 (F) ; ∀x∈ℝ, x²≥0 (V) ; ∀z∈ℂ, |z|=1 (F).
Négation Non P est vraie ssi P est fausse. Non(∀z, |z|=1) : ∃z∈ℂ, |z|≠1 (vraie).
« P et Q » vraie si P et Q le sont toutes deux. « P ou Q » fausse seulement si P et Q sont fausses.
Implication P ⇒ Q := « Non P ou Q ». Si vraie : P condition suffisante pour Q ; Q condition nécessaire pour P.
Équivalence P ⇔ Q := (P ⇒ Q) et (Q ⇒ P) : condition nécessaire et suffisante.

Quantificateurs

∀x∈E, P(x) : vraie pour tout x. ∃x∈E, P(x) : pour au moins un x. ∃! : un unique x. Ex : ∀n∈ℕ, n(n+1) pair ; ∃x∈ℝ, x(x−1)<0.

Négation Non(∀x, P(x)) ⇔ ∃x, Non P(x) ; Non(∃x, P(x)) ⇔ ∀x, Non P(x).
L'ordre compte ∀x∈ℝ ∃y∈ℝ : x+y>0 vraie ; ∃x∈ℝ ∀y∈ℝ : x+y>0 fausse. ∃x∈ℝ⁺ ∀y∈ℝ⁻ : −xy≥0 vraie ; ∀x∈ℝ⁺ ∃y∈ℝ⁻ : −xy≥0 vraie.

2 · Raisonnements

Direct On suppose P et on montre Q. Ex : a,b∈ℚ ⇒ a+b∈ℚ.
Cas par cas On traite A puis son complémentaire. Ex : ∀x∈ℝ, |x−1| ≤ x²−x+1 (cas x≥1, x<1).
Contraposée Montrer Non Q ⇒ Non P. Ex : n² pair ⇒ n pair.
Absurde On suppose P vraie et Q fausse, on cherche une contradiction. Ex : a,b≥0, a/(1+b)=b/(1+a) ⇒ a=b. Contraposée ou absurde : bien préciser, ne pas changer en cours de rédaction.
Contre-exemple Pour réfuter ∀x, P(x) il suffit d'un x où P est fausse. Ex : « tout entier positif est somme de trois carrés » est fausse.
Récurrence 1) Initialisation : P(0) (ou P(n₀) si n≥n₀). 2) Hérédité : P(n) ⇒ P(n+1). 3) Conclusion. Double : P(0),P(1) puis P(n),P(n+1) ⇒ P(n+2). Forte : P(0) puis P(1..n) ⇒ P(n+1). Ex : 2ⁿ>n ; U₀=0, U₁=1, Uₙ₊₂=2Uₙ₊₁−Uₙ ⇒ Uₙ=n.

3 · Espaces vectoriels

K = ℝ ou ℂ. E muni de + (interne) et · (externe, K×E→E).

K-ev 1) (E,+) groupe abélien : associatif, commutatif, neutre 0_E, symétrique −x. 2) ∀λ,µ∈K : λ(x+y)=λx+λy ; (λ+µ)x=λx+µx ; λ(µx)=(λµ)x ; 1·x=x. Ex : ℝ, ℝ² et ℂ sont des ℝ-ev.
Sous-espace F ⊂ E ssi i) 0_E∈F ii) X+Y∈F iii) αX∈F. Ex : {0}×ℝ, {x−y=0} sont des sev de ℝ² ; H={(x,2x+1)} n'en est pas un (0∉H).
Combinaison linéaire x=Σαᵢxᵢ ; elles forment un sev. Ex : (2,−3,0)=2(1,0,0)−3(0,1,0).
Génératrice Tout vecteur est c.l. des xᵢ ; E=⟨x₁..xₙ⟩. Dimension finie : il existe une famille génératrice finie.
Libre Σαᵢxᵢ=0 ⇒ tous αᵢ=0 ; sinon liée. {(1,1,0),(0,1,1)} libre ; {(1,0,0),(0,1,0),(1,1,0)} liée.
Base Libre et génératrice. Tout x s'écrit de façon unique Σλᵢeᵢ (coordonnées). Bases canoniques de ℝ², ℝ³.
Propriétés (dim E = n) Existence d'une base ; toutes les bases ont n vecteurs ; libre à n vecteurs ⇒ base ; génératrice à n vecteurs ⇒ base ; libre ≤ n vecteurs ; génératrice ≥ n ; F sev ⇒ dim F ≤ dim E ; dim{0}=0.

Exercices : {3x−2y=0}⊂ℝ², {x−3y+z=0}⊂ℝ³ (sev, génératrice, dim) ; {2x+3y+5z=0} ; (0,1,1),(1,0,1),(1,1,0) base de ℝ³ ; {e₁,e₂} libre non génératrice dans ℝ³ ; {e₁,e₂,e₃,(1,1,1)} génératrice non libre.

4 · Calcul matriciel

Matrice A=(aᵢⱼ)∈Mₙ,ₚ(K) : n lignes, p colonnes. Particulières : nulle, carrée Mₙ(K), triangulaire sup. (aᵢⱼ=0 si j<i), inf. (aᵢⱼ=0 si i<j), diagonale, identité Iₙ.
Somme (même taille) cᵢⱼ=aᵢⱼ+bᵢⱼ. Produit par λ : dᵢⱼ=λaᵢⱼ. Propriétés : A+B=B+A, (A+B)+C=A+(B+C), A+0=A, (α+β)A=αA+βA, α(A+B)=αA+αB.
Produit A∈Mₙ,ₚ, B∈Mₚ,q : cᵢⱼ=Σₖ₌₁ᵖ aᵢₖbₖⱼ, C∈Mₙ,q. Défini si #colonnes(A)=#lignes(B). Non commutatif. Si AB=BA : (A+B)ⁿ=Σₖ₌₀ⁿ C(n,k)AᵏBⁿ⁻ᵏ. (AB)C=A(BC), A(B+C)=AB+AC, (A+B)C=AC+BC, A0=0A=0, IₙA=A=AIₚ.
Ex : [[1,2],[0,−1],[5,3]]·[[1,−2,0,3,0],[−7,0,2,1,0]] = [[−13,−2,4,5,0],[7,0,−2,−1,0],[−16,−10,6,18,0]].
Transposée ᵗA∈Mₚ,ₙ de terme aⱼᵢ. ᵗ(A+B)=ᵗA+ᵗB ; ᵗ(λA)=λᵗA ; ᵗ(ᵗA)=A ; (ᵗA)ᵏ=ᵗ(Aᵏ).

Déterminant (A∈Mₙ(K))

n=1 : det(a)=a. n≥2 : det A=Σᵢ aᵢ₁(−1)ⁱ⁺¹det(Aᵢ₁) (Aᵢ₁ : ligne i et colonne 1 enlevées). 2×2 : det[[a,b],[c,d]]=ad−bc ; det[[1,2,3],[4,5,6],[7,8,9]]=0. Ligne ou colonne nulle ⇒ det=0. Diagonale ou triangulaire : produit des aᵢᵢ.
det(AB)=det A·det B ; det(λA)=λⁿdet A ; det A=det ᵗA.

Inverse

A inversible s'il existe B : AB=BA=Iₙ (B=A⁻¹). (A⁻¹)⁻¹=A ; (λA)⁻¹=λ⁻¹A⁻¹ ; (AC)⁻¹=C⁻¹A⁻¹.
Cofacteur cᵢⱼ=(−1)ⁱ⁺ʲdet(Aᵢⱼ) ; com(A)=(cᵢⱼ). Ex : A=[[1,2],[3,4]] → com(A)=[[4,−3],[−2,1]].
Th. A inversible ⇔ det A≠0, et alors A⁻¹=(1/det A)·ᵗcom(A).

Exercices : det de [[0,1,2],[1,1,2],[0,2,3]] et [[1,1,2],[1,2,1],[2,1,1]] ; inverses de [[2,−4],[−3,1]], [[0,1,2],[1,1,2],[0,2,3]], [[1,1,2],[1,2,1],[2,1,1]], [[1,2,3],[0,1,2],[−1,−4,−1]].

5 · Nombres complexes

ℂ contient ℝ et i (i²=−1) ; tout z s'écrit z=x+iy de façon unique ; pas de relation d'ordre. z=z′ ⇔ x=x′ et y=y′.
Conjugué z̄=x−iy. conj(z̄)=z ; conj(z+z′)=z̄+z̄′ ; conj(zz′)=z̄z̄′ ; conj(1/z′)=1/z̄′ ; conj(z/z′)=z̄/z̄′ ; z̄=z⇔z∈ℝ ; z̄=−z⇔z∈iℝ.
Re z=(z+z̄)/2 ; Im z=(z−z̄)/2i ; Re, Im linéaires sur ℝ.
Module |z|=√(x²+y²). |z|≥0 ; |z|=0⇔z=0 ; |z|²=zz̄ (si |z|=1 : z̄=1/z ; sinon 1/z=z̄/|z|²) ; |z̄|=|z| ; |zz′|=|z||z′| ; |z/z′|=|z|/|z′| ; |z+z′|≤|z|+|z′|.

6 · Fonctions usuelles

ln Primitive de 1/x sur ℝ*₊ nulle en 1 ; croissante ; ln(1+x)≤x (x>−1). ln(ab)=ln a+ln b ; ln(1/a)=−ln a ; ln(a/b)=ln a−ln b ; ln(aʳ)=r ln a. Limites : ln→+∞ (+∞), →−∞ (0⁺), ln x/x→0, x ln x→0 (0⁺), ln x/(x−1)→1 (x→1), ln(1+x)/x→1 (x→0).
exp Réciproque de ln ; exp′=exp ; exp x≥x+1 ; exp(x+y)=exp x·exp y ; exp(−x)=1/exp x ; exp(x−y)=exp x/exp y ; (exp x)ʳ=exp(rx). Limites : +∞→+∞ ; −∞→0 ; exp x/x→+∞ ; x exp x→0 (−∞) ; (exp x−1)/x→1 (0).
Puissances Pα(x)=xᵅ=exp(α ln x), Pα′=αxᵅ⁻¹ ; croissante si α>0, décroissante si α<0. α>0 : Pα(0)=0 (continue sur [0,+∞[) ; α>1 : Pα′(0)=0 ; 0<α<1 : Pα′→+∞ en 0.
Comparaisons (ln x)ᵅ/xᵝ→0 (+∞) ; xᵅ|ln x|ᵝ→0 (0⁺) ; (exp x)ᵅ/xᵝ→+∞ ; |x|ᵅexp(βx)→0 (−∞) ; aˣ/xᵅ→+∞ (a>1).
Trigonométrie sin′=cos, cos′=−sin ; cos²+sin²=1. tg=sin/cos sur ℝ∖{π/2+πℤ}, tg′=1/cos²=1+tg². cotg=cos/sin sur ℝ∖πℤ, cotg′=−1/sin²=−1−cotg². tg, cotg impaires, π-périodiques.
Réciproques
arcsin : [−1,1]→[−π/2,π/2], impaire, arcsin′=1/√(1−x²) sur ]−1,1[. sin(arcsin x)=x ; arcsin(sin x)=x sur [−π/2,π/2] (2π-périodique, impaire).

Intégrales impropres de 1ʳᵉ espèce

Borne infinie : ∫ₐ^{+∞}f=lim_{b→+∞}∫ₐᵇf ; convergente si la limite est finie. ∫₁^{+∞}dt/t² converge (=1) ; ∫₁^{+∞}dt/t diverge. Linéarité si les deux convergent ; I et αI (α≠0) de même nature ; I converge et J diverge ⇒ I+J diverge. Fonction complexe : converge ⇔ Re et Im convergent.
